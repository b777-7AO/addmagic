# addmagic · website

Static site for AddMagic UG (haftungsbeschränkt), Bensheim. No build step: `index.html`, `styles.css`, `app.js`, `legal.html`, `assets/`.

- Bilingual (DE/EN) via the dictionary in `app.js`; language and theme are stored in localStorage.
- Dark and light theme, tokens from the 2026 brand system (Outfit + DM Sans, self-hosted).
- Preview: `python3 -m http.server 8742` in this folder.
